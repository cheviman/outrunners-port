Native port of the Sega arcade game OutRunners (1992) by cheviman (BSD-3-Clause), built for the console. Add this game to Hakchi, open the game's folder and put your own `orunners.zip` there (the MAME `orunners` set, World). The first time it runs it makes its assets from the set, which takes a moment. The home button leaves the game. No game data is included.
