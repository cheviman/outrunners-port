OutRunners 1.1.3: SET UP WHEEL, for a racing wheel the game did not see, and a fix for building on Linux. As
before, nothing of the game comes in these packages: keep your own `orunners.zip` (MAME's ROM set, World)
beside the game, and it takes its assets out of it the first time it starts. The devices' games (Switch,
Android, Anbernic) are made again with the tools in the package.

**New in OPTIONS > STEERING**

- **SET UP WHEEL**: a racing wheel the game did not see, a Thrustmaster T300RS on Windows for one (SDL, which
  reads the controllers, has no layout for it), is set up once. The game asks for its controls one by one:
  turn the wheel left, press the gas and let go, the brake, then the buttons for shift up, shift down and
  start. The wheel is then player 1's controller, and the INPUT TEST comes next to check it; set WHEEL
  ROTATION to the wheel's own turn and the DEAD ZONE to 0%. Separate pedals and pedals combined in one axis
  both work. On Windows, Linux and macOS.
- **`gamecontrollerdb.txt`**: SET UP WHEEL keeps the layout there, beside `controls.ini`, in SDL's own format,
  a line a device. A layout made elsewhere (SDL's community's `gamecontrollerdb.txt`, a tool's) can go there
  too: both games read it as they start.

**Fixed**

- **Building from the source on Linux** (#17): a build without optimization (CMake with no build type, as
  the README's) could stop with a segmentation fault, with the assets its first run takes out. The video's
  threads now read the sprite graphics' lookup once, and a build with no build type is optimized, as the
  packages are.

`README.txt` in the package says what each tool needs. What a tool makes is yours alone: never share it.
